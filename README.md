# ハンドボール対戦

スマホのブラウザで遊べる、友だちとのオンライン1対1ハンドボールゲームです（インストール不要）。

## 遊び方

1. ページを開いて「部屋を作る」を押す
2. 「招待URLを共有」でLINEなどから友だちにURLを送る（または5文字の部屋コードを伝える）
3. 友だちがURLを開く（または「部屋に入る」でコードを入力）と試合開始。1試合5分、同点なら延長（ゴールデンゴール）

一人で練習するときは「CPUと練習」。初めての人は「チュートリアル」で操作を一つずつ覚えられます。

## 操作（スマホは横持ち）

タイトル画面の「操作」で **かんたん**（最初はこちら）と **上級** を切り替えられます。

- かんたん：シュートは押すだけでキーパーのいない隅を自動で狙う／パスは押すだけで一番良い味方へ／守備は自動でボールに近い選手に切替、相手に正面から近づくと自動でカット
- 上級：下の表のとおり、狙い・パス先・カットを全部自分で操作

| ボタン | 攻撃中 | 守備中 |
| --- | --- | --- |
| 左下スティック | 選手を動かす | 選手を動かす |
| パス | スティック方向の味方へパス | ボールに一番近い選手に切替 |
| ロング | 前線の味方へロングパス | — |
| シュート | 長押しで強く、離して発射（スティックで左右を狙う） | ボールを奪いに行く（カット。正面からが狙い目、外すと一瞬よろける） |
| ダッシュ | 押している間だけ速く走る（スタミナを多く使う） | 同じ |
| 交代（右上） | いちばん疲れている選手をベンチの元気な選手と交代 | 同じ |

**フェイント**
- シュートフェイント：シュートボタンを長押し中にパス → シュートを取り消し、近くの守備とキーパーを惑わせる（しっかり構えてからでないと効かない）
- 切り返し：ボールを持ってスティックを素早く逆に倒す → 鋭く切り返し、目の前の守備を置き去りにする
- 待ち時間なし。ただし一度だまされた守備は約1秒間は同じ手にかからない

**守備とルール**
- カットは確率。正面から、ドリブル中（3秒以上持っている）の相手ほど取りやすい。後ろからはほぼ取れない
- シュートコースに立っている守備はシュートをブロックできる。フェイントで守備をずらしてから打とう
- パッシブプレー：15秒シュートしないと警告（✋パッシブ）、22秒で相手ボール
- ゴールに近い（12m以内）シュートはジャンプシュート。空中ならゴールエリアの上を飛び越えて打てる
- 9mラインの内側で、シュートしようとする相手を後ろからカットするとファウルで7mスロー。7mスローは5秒以内に打つ
- 画面下中央のミニマップでコート全体の位置がわかる

**スタミナと交代**
- 走るとスタミナが減り、ダッシュは大きく減る。疲れると足もシュートも遅くなる（左上のバーで確認）
- ベンチ6人と何度でも交代できる（ハンドボールと同じ自由交代）。ベンチの選手は回復する。CPUも自動で交代する

パソコンでは WASD/矢印キーで移動、J=パス、K/スペース=シュート、L=ロング、Shift=ダッシュ、C=交代。

## つながらないとき

モバイル回線どうしだと直接つながらないことがあります。その場合は `src/net/ice.js` に中継（TURN）サーバーを追加してください。

## 開発

```bash
npm test               # ゲームロジックのテスト
node tools/serve.mjs   # http://localhost:8080 で起動
```
